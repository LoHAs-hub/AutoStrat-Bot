# 循環 00 驗收

## 功能情境

1. 首頁可看見 TMF、當前循環、下一任務、確認事項、待決事項及實際保存記錄。
2. 任務列表能篩選；新增任务有名稱、內容、階段及完成條件。已排入只是規劃，不啟動 Agent。
3. 未完成依賴不能開始後續任务；任務完成時沒有證據會拒絕。重開前置任務不會悄悄讓後續進度失效。
4. 新增原則保存原話、範圍与性質；封存不刪除。P001 原話是「嚴格執行交易計劃」。
5. 執行固定示例引用當下啟用原則，明示沒有 LLM、行情或績效；缺資料與風控便停止。
6. 重載/重啟後仍有資料；另一視窗使用舊版本儲存會得到衝突訊息；相同請求重試不重複新增。
7. 無身分、不屬於擁有者、跨來源寫入與錯誤 JSON 被拒絕，且不破壞資料。
8. 交接摘要含任務/證據/原則/未決問題；完整 JSON 包含事件与示例歷史。
9. 手機與桌面可閱讀，dialog 可鍵盤操作，錯誤保留輸入。若沒有瀏覽器可用，須明說視覺/互動 QA 未驗證。

## 技術驗證

`npm run verify` 檢查語法、來源/任务完整性、API 整合、SQLite 保存、版本併發和 Worker 建置。測試呼叫實際 API handler 與 SQLite，不以 mock 假裝保存成功。

沒有 Pine、行情、策略效益或 TradingView 整合測試，因這些功能未實作。WebMCP 可在支援 document.modelContext 的瀏覽器註冊；一般瀏覽器不受影響。支援 context 的端到端測試須另外記錄，不能由 source inspection 代替。
